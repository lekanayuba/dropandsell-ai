DropandSell Information Security Policy

Document Version: 1.0  |  Effective Date: April 2026  |  Last Reviewed: April 2026
Organisation: DropandSell  |  Website: https://dropandsell.online

1. Purpose

This policy establishes the information security framework for DropandSell, an e-commerce automation platform. It defines the security controls, practices, and responsibilities to protect customer data, seller information, and business operations from unauthorised access, disclosure, alteration, or destruction.

2. Scope

This policy applies to all systems, data, personnel, and third-party services involved in the operation of DropandSell, including but not limited to: the web application, databases, APIs, marketplace integrations (eBay, Shopify, Amazon, TikTok Shop), and all customer and seller data processed by the platform.

3. Data Protection & Encryption

  • Encryption in Transit: All data transmitted between users, our servers, and third-party APIs is encrypted using TLS 1.2 or higher (HTTPS).
  • Encryption at Rest: Sensitive data stored in our databases is encrypted at rest using AES-256 encryption provided by our cloud infrastructure.
  • Data Classification: We classify data into categories (Public, Internal, Confidential, Restricted) and apply appropriate security controls based on classification level.
  • API Credentials: All marketplace API keys, OAuth tokens, and secrets are stored as encrypted environment variables, never in source code or logs.

4. Access Control

  • Principle of Least Privilege: Access to systems and data is granted on a need-to-know basis. Each team member only has access to the systems required for their role.
  • Authentication: All administrative access requires strong passwords and multi-factor authentication (MFA).
  • Session Management: User sessions are secured with HTTP-only cookies, automatic timeouts, and CSRF protection.
  • User Data Isolation: The application enforces strict multi-tenancy — each user can only access their own data, orders, products, and store connections.

5. Network Security

  • Infrastructure: The application is hosted on a managed cloud platform with built-in network isolation, firewall protection, and DDoS mitigation.
  • Network Segregation: Application services run in isolated containers with network-level separation between components.
  • Monitoring: We monitor for suspicious activity including unusual API usage patterns, failed authentication attempts, and unauthorised access attempts.
  • Updates: All system dependencies, frameworks, and libraries are regularly updated to address known vulnerabilities.

6. Endpoint Security

  • All company devices used for development and administration have endpoint protection software installed with real-time scanning enabled.
  • Automatic security updates are enabled on all company endpoints.
  • Screen locking, password complexity requirements, and encrypted storage are enforced on all devices.

7. Vulnerability & Threat Management

  • Regular security reviews and code audits are conducted to identify and remediate vulnerabilities.
  • Dependencies are scanned for known vulnerabilities and updated promptly when patches are available.
  • Input validation and output encoding are implemented to prevent injection attacks (SQL injection, XSS, etc.).

8. Incident Response

  • Detection: Security incidents are identified through monitoring, user reports, and automated alerting.
  • Response: Incidents are investigated promptly with defined escalation procedures.
  • Notification: Affected users, partners, and regulatory authorities are notified in accordance with applicable data protection regulations (UK GDPR).
  • Remediation: Root cause analysis is performed and corrective measures are implemented to prevent recurrence.

9. Data Retention & Deletion

  • Customer data is retained only for as long as necessary to provide the service.
  • Upon account deletion or contract termination, all associated customer data is securely deleted within 30 days.
  • We honour data subject access requests (DSARs) and deletion requests in compliance with UK GDPR.

10. Third-Party Integrations

  • All third-party marketplace integrations (eBay, Shopify, Amazon, TikTok Shop) use official OAuth 2.0 authentication flows.
  • API tokens are refreshed automatically and stored securely.
  • We only request the minimum permissions (scopes) required for the integration to function.

11. Privacy Compliance

  • We maintain a regularly updated privacy policy available at https://dropandsell.online/privacy.
  • Data processing activities comply with UK GDPR and applicable data protection laws.
  • We assist sellers and platform partners with data deletion, update, and access requests upon receipt.

12. Policy Review

This policy is reviewed and updated at least annually, or whenever significant changes to the platform, infrastructure, or regulatory requirements occur.
